# SEO page proposals

Add one `<proposalId>.json` file before creating a new indexable URL. The proposal must use `data/seo-proposal.schema.json`, include the future stable page ID, and pass `npm run qa:seo-new-pages`.

The opportunity score is recomputed in CI. Scores of 70 or more are eligible for normal approval. Scores from 55–69 require an explicit exception. Lower scores cannot be approved. R2–R4 proposals require a human approval record; no proposal authorises outreach sending.
